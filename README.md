# CEMS – Central Electoral Management System

A full-stack web-based electoral management dashboard built using **Node.js, Express.js, MySQL, EJS, HTML, CSS, and JavaScript**.

## Features

- Dashboard with live elector statistics
- 300+ voter dataset stored in MySQL
- Search elector by name or state
- Migration request system
- Real-time state updates in database
- CSV export of voter records
- Charts and analytics dashboard
- Dark / Light mode UI
- Clean premium responsive interface

## Tech Stack

- Node.js
- Express.js
- MySQL
- EJS
- HTML5
- CSS3
- JavaScript
- Chart.js
